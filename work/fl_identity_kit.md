## 1. Typography Selection

| Role | Font Family | Usage |
|---|---|---|
| **Heading Font** | `Inter` (sans-serif, weight 700) | Page headers, title banners, section titles. |
| **Body Font** | `Inter` (sans-serif, weight 400) | Body prose, documentation, descriptions. |
| **Code Font** | `JetBrains Mono` (monospace, weight 500) | Metrics, code snippets, terminal outputs, JSON payloads. |

## 2. Color Palette (Tight 4-Color Spec)

| Color Element | Hex Code | Color Name | Visual Role |
|---|---|---|---|
| **Primary Background** | `#0F172A` | Slate Dark 900 | Calm, dark background framing technical content. |
| **Container / Cards** | `#1E293B` | Slate Dark 800 | Subtly elevated containers for code blocks & data tables. |
| **Primary Text** | `#F8FAFC` | Slate Light 50 | High contrast near-white for crisp prose readability. |
| **Accent Color** | `#14B8A6` | Teal 500 | Single accent color highlighting metrics (Precision@50, 3.08x lift). |

## 3. Logo & Favicon Specification

- **Monogram Logo**: Text-based monogram `G / ML` set in `Inter` 700 bold, styled with Teal `#14B8A6` accent border.
- **Favicon Specification**: SVG icon featuring a clean minimalist terminal chevron `>_` set inside a `#0F172A` square with `#14B8A6` teal fill.

## 4. Two-Line Style Note for Claude Project

> **Fonts & Hex**: `Inter` for prose, `JetBrains Mono` for code; Palette: `#0F172A` bg, `#1E293B` card, `#F8FAFC` text, `#14B8A6` teal accent.  
> **Visual Mood**: Objective, dark-mode technical terminal aesthetic that frames empirical ML metrics without decorative distractions.
